&#x20;Sales Data Analytics - Project Plan



&#x20;Project Objectives

\- Select and inspect a sales dataset.

\- Clean missing and duplicate values.

\- Perform exploratory data analysis using Python.

\- Create at least five data visualizations.

\- Develop an interactive Power BI dashboard.

\- Identify business insights and recommendations.



&#x20;Tools

Python, Pandas, NumPy, Matplotlib, Seaborn, Power BI, Git, and GitHub.



Expected Outcome

A complete sales analytics project containing a prepared dataset, analysis, visualizations, an interactive dashboard, and project documentation.
