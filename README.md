\# Sales Data Analytics Project



\## Project Overview

This project analyzes sales data to identify trends, evaluate business performance, and generate useful insights.



\## Objectives

\- Prepare and clean the sales dataset.

\- Perform Exploratory Data Analysis (EDA) using Python.

\- Create meaningful data visualizations.

\- Build an interactive Power BI dashboard.

\- Provide business insights and recommendations.



\## Tools Used

\- Python

\- Pandas and NumPy

\- Matplotlib and Seaborn

\- Power BI

\- Git and GitHub

Project setup completed. Dataset preparation and analysis are in progress.
